# Mathcad → Markdown и Word

Конвертер XML-документов Mathcad 15 (`.xmcd`) в UTF-8 Markdown (`.md`) или Word (`.docx`). Нужен **Python 3.10 или новее**. Конвертация работает локально, без установленного Mathcad и сторонних Python-библиотек. Для DOCX дополнительно нужен **Pandoc**, доступный в `PATH`.

## Быстрый запуск в Windows

Дважды нажмите **`run-gui.cmd`**. В открывшемся окне выберите файлы XMCD, формат **Markdown (.md)** или **Word (.docx)**, папку результатов и нажмите **«Конвертировать»**. По умолчанию выбран Markdown, результаты записываются в `output`.

Либо запустите из папки проекта:

```powershell
python convert.py --gui
```

Графический интерфейс использует Tkinter, входящий в обычную установку Python для Windows. Если Tkinter отсутствует, доступна командная строка.

## Pandoc для экспорта Word

Установите Pandoc по [официальной инструкции](https://pandoc.org/installing.html). Установщик Windows добавляет программу в `PATH`. Затем перезапустите конвертер; если запускаете его из терминала, откройте новый терминал. Проверка доступности:

```powershell
pandoc --version
```

Если Pandoc не найден, при выборе DOCX программа покажет сообщение о необходимости установки со ссылкой на инструкцию. В командной строке то же сообщение выводится как ошибка. Markdown по-прежнему работает без Pandoc.

Экспорт Word выполняется по цепочке **XMCD → временный Markdown → Pandoc → DOCX**. Изображения включаются внутрь DOCX, поддерживаемые формулы преобразуются в уравнения Word. Временный Markdown и изображения удаляются после конвертации; для передачи результата достаточно одного `.docx`. Установка Microsoft Word и LaTeX для экспорта не требуется.

## Командная строка

Один файл, Markdown рядом с исходником:

```powershell
python convert.py "задание 1 УП.xmcd"
```

Все XMCD из текущей папки в отдельную папку (без рекурсивного обхода):

```powershell
python convert.py . --output-dir output
```

Конкретное имя результата, маска или несколько входных файлов:

```powershell
python convert.py "задание 2.xmcd" -o "output/Расчёт.md"
python convert.py "*.xmcd" -d output
python convert.py "задание 1 УП.xmcd" "задание 2.xmcd" -d output
```

DOCX для одного файла или всех примеров:

```powershell
python convert.py "задание 2.xmcd" --format docx -d output
python convert.py . --format docx --output-dir output
python convert.py "задание 2.xmcd" -o "output/Расчёт.docx"
```

Параметр `--format` (кратко `-f`) принимает `md` или `docx`. Если он не задан, формат определяется по расширению `--output`; в остальных случаях используется Markdown. Явно выбранный формат и расширение выходного файла должны совпадать.

Существующие MD и DOCX защищены от перезаписи. Для намеренного обновления добавьте `--force` или включите соответствующий флажок в окне. Исходные XMCD не изменяются. При ошибке одного файла пакетная обработка продолжает остальные; код завершения `1` означает хотя бы одну ошибку, `0` — завершённую конвертацию. Предупреждения о неполном представлении конструкций и предупреждения Pandoc выводятся отдельно. Если Pandoc завершился с ошибкой, существующий DOCX сохраняется даже при `--force`.

Для установки команды `xmcd2md` в собственное Python-окружение можно выполнить `python -m pip install .`. Сборка пакета использует `setuptools`; pip может скачать его при установке. Запуск через `convert.py` установки пакета и `setuptools` не требует.

## Что сохраняется

- Русский текст, абзацы, заголовки, базовые выделения и формулы внутри текста.
- Определения переменных, арифметика, дроби, степени, корни, индексы, функции, матрицы и комплексные числа.
- Сохранённые численные и символьные результаты; единицы измерения и настройка мнимой единицы `i`/`j`.
- Схемы, рисунки и другие объекты с сохранённым растровым предпросмотром.
- Порядок чтения по вертикальным координатам и базовым линиям, слева направо внутри строки. Идентификаторы регионов остаются в HTML-комментариях для сверки с исходником.

В Markdown формулы записываются как LaTeX между `$$`, формулы внутри абзаца — между `$`. Например:

```markdown
$$
I \coloneqq \frac{U}{R} = 10
$$
```

При экспорте Markdown изображения записываются в соседнюю папку `<имя файла>_assets`. Переносите её вместе с Markdown: ссылки относительные, имена с пробелами и кириллицей корректно кодируются в URL. Редактор Markdown должен поддерживать математический LaTeX для отображения формул.

## Ограничения

Это преобразование содержимого, а не воспроизведение листа Mathcad по пикселям. Многоколоночное размещение превращается в последовательность блоков; шрифты, цвет, поля и разрывы страниц не копируются полностью.

Конвертер **не пересчитывает** выражения. Он берёт результаты из сохранённого файла и сохраняет их полную записанную точность. Поэтому число знаков после запятой может отличаться от округления на экране Mathcad. Перед экспортом при необходимости пересчитайте и сохраните лист в Mathcad.

Не все конструкции языка Mathcad реализованы. Для неизвестной конструкции выводятся предупреждение, исходный XML и доступный предпросмотр; если предпросмотра нет — явная отметка. Графики и OLE-объекты сохраняются как изображения, без интерактивности и редактирования их внутреннего содержимого. Встроенный код и внешние ссылки не выполняются.

Поддерживаются XML-файлы `.xmcd`; старый бинарный `.mcd`, сжатый `.xmcdz` и документы Mathcad Prime `.mcdx` в эту версию не входят. Оформление DOCX задаёт Pandoc; после конвертации стоит проверить разбиение страниц и длинные формулы в Word.

## Проверка

Из корня проекта в PowerShell:

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
```

Тесты проверяют порядок и полноту регионов, приоритет операций, матрицы с хранением по столбцам, сохранённые результаты, inline-формулы, экспорт PNG, повреждённые XML, неподдерживаемые конструкции и защиту файлов от перезаписи. Дополнительно проверяются выбор формата, сообщение при отсутствии Pandoc и обработка ошибок экспорта DOCX. Интеграционные тесты используют пользовательские `.xmcd` из корня, если они доступны; тесты с настоящим Pandoc пропускаются, если он не установлен.

Проверены три примера проекта:

| Исходник | Регионов | Формул | Текстовых блоков | Изображений |
|---|---:|---:|---:|---:|
| задание 1 УП.xmcd | 340 | 300 | 38 | 2 |
| задание 2.xmcd | 492 | 382 | 100 | 10 |
| Ручной расчёт ПП для 1 и 2 л.р.xmcd | 257 | 118 | 139 | 0 |

Во втором файле одна формула находится внутри текстового блока и включена в счётчик регионов. В метаданных примеров указаны Mathcad 14/14.1 и схема `worksheet30/math30`; эти файлы открываются в Mathcad 15. Примеры не покрывают все возможные конструкции Mathcad.

## Использование из Python

После установки пакета:

```python
from xmcd2md import convert_file

result = convert_file("расчёт.xmcd", "output/расчёт.md")
print(result.output_path)
print(result.warnings)

word_result = convert_file("расчёт.xmcd", "output/расчёт.docx")
# Без явного выходного пути:
word_result = convert_file("расчёт.xmcd", output_format="docx")
```

Разбор листа (`converter.py`), формулы (`math_renderer.py`), изображения (`assets.py`) и экспорт через Pandoc (`pandoc.py`) разделены, чтобы расширять поддержку XMCD независимо от интерфейса запуска.
